Field guide

SEO, AEO, GEO — what's the difference for car dealers?

Most dealers use these three terms interchangeably. They are not the same thing, and the confusion costs real money because the dealer ends up buying the wrong service or measuring the wrong outcome.

SEO

Search Engine Optimization

The discipline of being found in traditional search engines that return a list of links. Primary: Google web search, Bing. The user picks from the list. Signals: backlinks, content depth, Core Web Vitals, schema, local citations. Outcome: ranking position, organic clicks.

Still where most high-intent dealer queries land, especially "[brand] dealer near me" and "where to buy a [model] in [city]" type searches.

AEO

Answer Engine Optimization

The discipline of being cited in answer engines that assemble an answer rather than returning a list. Primary: ChatGPT, Perplexity, Gemini, Claude, Copilot, plus Google's featured snippets and People Also Ask. Signals: entity reinforcement, conversational content, schema, llms.txt, third-party citations. Outcome: citation frequency in AI answers.

Where research-stage buyers form impressions before they ever touch Google.

GEO

Generative Engine Optimization

Functionally synonymous with AEO. Some practitioners draw a slight distinction: GEO targets generative AI engines specifically (ChatGPT, Perplexity, Gemini, Claude, Copilot) while AEO covers both generative engines and classical answer engines. In practice, treat AEO and GEO as the same discipline.

The terminology is still settling. Most dealer agencies use both terms. This marketplace covers both.

The mental model

SEO targets the link list. AEO and GEO target the answer.

A car dealer site can rank #1 in Google web search and be invisible in ChatGPT. The reverse is also true. Most dealers need to invest in both: SEO for direct conversion traffic, AEO/GEO for research-stage visibility.

The dealer-search-strategy skill in this marketplace produces a unified strategy covering all three.

Why this exists

Most dealer AI projects fail before the vendor is even chosen.

There is a reason most dealer AI projects underperform. It is not the AI. It is the dealership. A store with a messy CRM, a slow website, no governance, and a BDC running on hope cannot install a chatbot and suddenly become a tech company. The AI exposes the cracks faster. The shiny thing on top only performs when the boring foundation underneath is real.

Install

Three paths, ordered by friction

Pick whichever fits your setup. The easiest path works in any agent that can read GitHub. The Claude Code path is for users who want the formal plugin marketplace flow. The manual path is for developers who want to read the source before installing.

1. Just ask your agent (easiest)

Install this: https://github.com/arielcoro/dealer-ai-skills

Paste that line into Claude Code, Cursor, Cline, Codex, Gemini CLI, Windsurf, Cowork, or any agent that can read a GitHub URL. The agent inspects the marketplace and installs the skills it needs. Works whether or not the agent's runtime supports the formal /plugin command.

2. Claude Code plugin marketplace

/plugin marketplace add arielcoro/dealer-ai-skills
/plugin install dealer-ai-readiness-audit@dealer-ai-skills

For Claude Code CLI and Claude Code Desktop users. The formal plugin marketplace flow. Does not run in Cowork mode or claude.ai chat; use path 1 in those environments. Get Claude Code at docs.claude.com/claude-code.

3. Manual install (for developers)

git clone https://github.com/arielcoro/dealer-ai-skills.git
cp -r dealer-ai-skills/skills/dealer-ai-readiness-audit ~/.claude/skills/

For users who want to read the source before installing or want to fork a skill. Drop the skill folder into the skills directory of any agent that supports the Agent Skills spec (Claude Code, Codex, Cursor, Cline, Gemini CLI, Windsurf).

Once installed: just ask

Whichever install path you used, skills activate from natural language. Try:

  • "Score my dealership on AI readiness."
  • "Audit my site for AEO."
  • "What is ChatGPT saying about my dealership?"

If you prefer not to install anything yourself, your agency or technical team can install Dealer AI Skills on their environment and run the diagnostics for you.

What we accept and what we do not

Accepted: new skills for real dealer operational problems, improvements to existing audits, platform-specific guidance (Dealer.com, DealerOn, DealerInspire), OEM-specific knowledge (GM, Ford, Stellantis, Toyota, Honda, Hyundai, Kia, Subaru, VW, Audi, Mazda), Spanish-language content, bug fixes, documentation.

Not accepted: vendor promotion, client-specific information, paid media management skills, F&I compliance frameworks (legal exposure), legal or financial advice, derivative work from paid third-party content.

Code of Conduct

Recognition. Contributors are credited in the commit history, in skill metadata where they substantially contributed, and in release notes when a release includes their work. Substantial contributors may be added as named authors on specific skills. The marketplace is free and MIT-licensed, so contributions are unpaid.
